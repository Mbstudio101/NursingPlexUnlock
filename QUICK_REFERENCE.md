## 🚀 Quick Start

### Web App (30 seconds)
```bash
npm install
npm run dev
# Open http://localhost:5173
```

### Extension (2 minutes)
```bash
# 1. Generate icons
open extension/generate-icons.html
# Click "Download All"

# 2. Install
chrome://extensions/ → Developer mode → Load unpacked
# Select extension/ folder

# 3. Use
Visit any NursingPlex review page → Auto-unlocks!
```
