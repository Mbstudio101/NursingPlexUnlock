## 🎮 How to Use

### Web Application

1. **Open the app**
   ```bash
   npm run dev
   # Open http://localhost:5173
   ```

2. **Browse questions**
   - Click "View All Questions"
   - Select an exam
   - Browse 503 questions

3. **Take quizzes**
   - Click "Start Quiz Mode"
   - Select an exam
   - Answer questions
   - See your score

4. **Search & filter**
   - Use search box
   - Filter by exam type
   - Find specific topics

5. **Export**
   - Click "Export"
   - Download as text file
   - Study offline

### Browser Extension

1. **Install**
   ```bash
   # Generate icons
   open extension/generate-icons.html
   
   # Install in Chrome
   chrome://extensions/ → Load unpacked
   ```

2. **Use**
   - Visit any NursingPlex review page
   - Questions automatically unlock
   - Study directly on NursingPlex

3. **Control**
   - Click extension icon
   - Toggle on/off
   - View statistics
   - Manual refresh

## 🔧 Troubleshooting

### Web App Not Starting?

```bash
# Clear cache
rm -rf node_modules
npm install

# Try again
npm run dev
```

### Extension Not Working?

1. Check if enabled (click icon)
2. Verify on NursingPlex review page
3. Check console (F12) for errors
4. Reload extension

### Questions Still Blurred?

1. Wait for page to load
2. Click "Refresh & Unlock"
3. Check console for errors
4. Reinstall extension
