# 🚀 Quick Install Guide - NursingPlex Unlock Extension

Get the extension running in 2 minutes!

## ⚡ Quick Start (Chrome/Edge/Brave)

### Step 1: Download Extension Files

The extension files are in the `extension/` folder. Make sure you have:
- ✅ manifest.json
- ✅ content.js
- ✅ content.css
- ✅ popup.html
- ✅ popup.js
- ✅ background.js
- ✅ icons/ folder (with PNG icons)

### Step 2: Open Extensions Page

1. Open Chrome/Edge/Brave
2. Go to: `chrome://extensions/`
   - Or: Click the three dots menu → More Tools → Extensions

### Step 3: Enable Developer Mode

1. Look for "Developer mode" in the top right
2. Toggle it ON
3. You should see new buttons appear

### Step 4: Load the Extension

1. Click "Load unpacked" button
2. Navigate to and select the `extension/` folder
3. Click "Select Folder"
4. The extension should appear in your list!

### Step 5: Pin the Extension

1. Click the puzzle piece icon 🧩 in the toolbar
2. Find "NursingPlex Unlock"
3. Click the pin 📌 icon to pin it

### Step 6: Test It!

1. Go to any NursingPlex exam review page
   - Example: https://nursingplex.com/review/advanced-med-surg-proctored-exam-mchps-1778479982
2. The extension will automatically unlock all questions
3. You should see a green notification: "NursingPlex Unlock Active"
4. All blurred questions are now visible!

---

## 🎯 That's It!

The extension is now installed and working. Every time you visit a NursingPlex review page, it will automatically unlock all questions.

## 🔧 Troubleshooting

### "Load unpacked" button not showing?
- Make sure Developer mode is enabled
- Try refreshing the extensions page

### Extension not working on NursingPlex?
- Click the extension icon
- Make sure the toggle is ON
- Click "Refresh & Unlock"
- Check the browser console (F12) for errors

### Questions still blurred?
- Wait a few seconds for the page to fully load
- Click "Refresh & Unlock" in the popup
- Try reloading the page (F5)

### Popup not showing?
- Make sure the extension is pinned to the toolbar
- Click the puzzle piece 🧩 and pin it
