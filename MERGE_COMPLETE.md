## 🚀 Unified Installation

### One Command Setup

**Mac/Linux:**
```bash

./unified-setup.sh
```

**Windows:**
```bash
unified-setup.bat
```

**What it does:**
- ✅ Installs web app dependencies
- ✅ Prepares browser extension
- ✅ Generates icons (if needed)
- ✅ Starts development server
- ✅ Opens browser automatically
- ✅ Guides you through extension install

**Time:** 3-5 minutes
